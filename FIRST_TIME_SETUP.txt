Welcome! Follow these steps to set up your Coffee Shop Cashier Management System.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 STEP 1: CHECK PREREQUISITES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Make sure you have:
  ☐ Python 3.8+ installed
  ☐ Node.js 16+ installed  
  ☐ MySQL Server 8.0+ installed and running

Test them:
  > python --version
  > node --version
  > mysql --version

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🗄️  STEP 2: CREATE MYSQL DATABASE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open MySQL Command Line Client or MySQL Workbench

2. Login:
   > mysql -u root -p
   (Enter your MySQL root password)

3. Create database:
   > CREATE DATABASE coffee_shop_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

4. Verify:
   > SHOW DATABASES;
   (You should see 'coffee_shop_db' in the list)

5. Exit:
   > EXIT;

For detailed instructions, see: docs/SETUP_DATABASE.md

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚙️  STEP 3: CONFIGURE BACKEND
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Navigate to backend folder:
   > cd coffeeShopPOS\backend

2. Create virtual environment:
   > python -m venv venv

3. Activate virtual environment:
   Windows:  > venv\Scripts\activate
   Mac/Linux: > source venv/bin/activate

   (You should see (venv) in your prompt)

4. Install dependencies:
   > pip install -r requirements.txt

5. Create .env file:
   a) Copy 'env_template.txt' 
   b) Rename the copy to '.env'
   c) Open '.env' in a text editor
   d) Find: DB_PASSWORD=your_mysql_password
   e) Replace 'your_mysql_password' with your ACTUAL MySQL root password
   f) Save the file

6. Initialize database:
   > python init_db.py

   You should see:
   ✓ Database tables created
   ✓ Created categories...
   ✓ Created users...
   ✓ Created products...
   ✓ Database initialized successfully!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎨 STEP 4: SET UP FRONTEND
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open a NEW terminal window

2. Navigate to frontend folder:
   > cd coffeeShopPOS\frontend

3. Install dependencies:
   > npm install

   (This may take a few minutes)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 STEP 5: START THE APPLICATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You need TWO terminal windows running:

TERMINAL 1 - Backend:
  > cd coffeeShopPOS\backend
  > venv\Scripts\activate    (Windows)
  > python run.py

  Should see: * Running on http://0.0.0.0:5000

TERMINAL 2 - Frontend:
  > cd coffeeShopPOS\frontend
  > npm start

  Should see: Local: http://localhost:3000/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎉 STEP 6: LOGIN AND TEST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open your browser
2. Go to: http://localhost:3000
3. Login with:

   ADMIN USER:
   Username: admin
   Password: admin123

   CASHIER USER:
   Username: cashier
   Password: cashier123

4. You should see the POS dashboard!

⚡ QUICK METHOD: USE STARTUP SCRIPTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After completing Steps 1-3 above, you can use these scripts:

Windows:
  1. Double-click: start_backend.bat
  2. Double-click: start_frontend.bat (in new window)

Mac/Linux:
  1. chmod +x start_backend.sh start_frontend.sh
  2. ./start_backend.sh
  3. ./start_frontend.sh (in new terminal)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to "Users" page (Admin only)
2. Click "Edit" on admin user
3. Change password to something secure
4. Click "Update"
5. Repeat for cashier user

⚠️  IMPORTANT: Change default passwords immediately!

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Can't connect to MySQL"
Solution: 
  - Make sure MySQL service is running
  - Check .env file has correct password
  - Verify database exists

Problem: "Module not found"
Solution:
  - Activate virtual environment
  - Run: pip install -r requirements.txt

Problem: "Port already in use"
Solution:
  - Stop other applications using port 5000 or 3000
  - Or change ports in run.py / vite.config.js

Problem: "Can't login"
Solution:
  - Make sure database was initialized (python init_db.py)
  - Check backend is running
  - Verify credentials (admin/admin123)
